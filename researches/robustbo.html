Robust Bayesian Optimization

Efficient Robust Bayesian Optimization for Arbitrary Uncertain inputs

Overview

This work presents an efficient approach to robust Bayesian optimization that can handle arbitrary uncertain inputs. The method addresses the challenge of optimization under uncertainty, which is common in real-world applications where input parameters may be noisy or uncertain.

Key Contributions

  • Robust Optimization: Developed a framework for robust Bayesian optimization that handles arbitrary input uncertainties
  • Efficiency Improvements: Introduced efficient algorithms that reduce computational complexity while maintaining robustness
  • Practical Applications: Demonstrated effectiveness in various real-world optimization problems

Publication

Lin Yang, Junlong Lyu, Wenlong Lyu, Zhitang Chen. “Efficient Robust Bayesian Optimization for Arbitrary Uncertain inputs.” NeurIPS 2023.
