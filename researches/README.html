Researches Directory Structure

每个研究工作现在都放在独立的目录下，包含所有相关文件。

目录结构

使用说明

  1. 添加新研究：在 researches/ 下创建新目录，目录名使用小写字母和下划线
  2. 创建 index.md：每个研究目录下必须有 index.md 文件作为详情页
  3. 添加资源：将图片、PDF 等文件放在对应的研究目录下
  4. 更新主页：在 source/index.md 的 researches 数组中添加新研究的信息

图片路径

在 index.md 中使用相对路径引用图片：

  • ./image.png - 引用同目录下的图片
  • ./subfolder/image.png - 引用子目录下的图片

Permalink

每个研究的 permalink 格式为：/researches/{目录名}/
